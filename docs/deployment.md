# Deployment (not performed by the author — you must do these steps)
1. Supabase project (check plan limits: Free = 50 MB max file, Edge Functions 256 MB RAM / 2 s CPU / 150 s wall). 2. `supabase link --project-ref <ref>`; `supabase db push` (migrations create the private bucket + policies). 3. `supabase secrets set ALLOWED_ORIGINS=https://<vercel-domain> MAX_UPLOAD_BYTES=10485760`; `supabase functions deploy`. 4. Auth settings: enable e-mail confirmation, set Site URL/redirects to the Vercel domain, min password 12. 5. Provision first admin by SQL (`update public.profiles set role='admin' where email='…'`) — never via the app. 6. Vercel: import repo, root dir `frontend`, env `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` (publishable key). 7. `SUPABASE_URL=… SUPABASE_ANON_KEY=… SUPABASE_SERVICE_ROLE_KEY=… npm run provision:demo` from your shell for fictional demo data (password printed once; don't publish). Keep the service-role key out of Git/Vercel/frontend.
