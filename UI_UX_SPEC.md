# UI/UX spec (as built)
Enterprise look: slate neutrals, single indigo accent, consistent radii, lucide icons, responsive sidebar→top bar, skeletons, empty states, toasts, confirm dialogs, pagination. Pages: /login, / dashboard, /documents (search+filters), /documents/new, /documents/:id (Overview/Sharing/History), /admin/audit, /admin/users (name/email search suggestions and account management), access-denied/not-found. UI hides controls by role for UX only; the server enforces everything. A 2026-10-21 local unauthenticated browser smoke check covered login validation, protected deep-link redirect, and the login page at a 390px viewport; authenticated pages and complete responsive behavior remain untested.
